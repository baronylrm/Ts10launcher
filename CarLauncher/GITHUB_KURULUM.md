# 🚗 CarLauncher APK — GitHub ile Ücretsiz Derleme

## Adım 1 — GitHub Hesabı Aç
→ https://github.com/signup (ücretsiz)

---

## Adım 2 — Yeni Repo Oluştur
1. https://github.com/new adresine git
2. Repository name: `CarLauncher`
3. Public seç (ücretsiz derleme için)
4. **Create repository** tıkla

---

## Adım 3 — Dosyaları Yükle
1. "uploading an existing file" linkine tıkla
2. ZIP içindeki **TÜM** dosyaları sürükle-bırak
   (CarLauncher klasörü içindeki her şey)
3. "Commit changes" tıkla

---

## Adım 4 — APK Otomatik Derlenir ✅
- Dosyaları yükler yüklemez GitHub otomatik başlar
- **Actions** sekmesine git
- Sarı ● = derliyor (2-3 dakika)
- Yeşil ✓ = hazır!

---

## Adım 5 — APK'yı İndir
1. Actions → en son iş → aşağı kaydır
2. **Artifacts** bölümünde **CarLauncher-TS10-APK** yazar
3. Tıkla → ZIP indir → içinde `app-debug.apk`

---

## Adım 6 — TS10'a Yükle
1. `app-debug.apk` dosyasını USB belleğe kopyala
2. USB'yi TS10'a tak
3. Dosya Yöneticisi → APK → Yükle
4. Settings → Security → Unknown Sources → İzin ver
5. HOME tuşu → **CarLauncher → Her Zaman** seç

---

## ⚠️ Önemli Not
Eğer Actions sekmesinde hata görürsen (kırmızı ✗):
- Actions → iş adına tıkla → hata mesajını göster
- Mesajı bana ilet, düzeltirim

---

## 🔄 Güncelleme Nasıl Yapılır?
Herhangi bir dosyayı GitHub'da düzenle → otomatik yeni APK derlenir.
